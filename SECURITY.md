# Security Policy

## Supported Versions

| Version | Supported          | PHP           |
|---------|--------------------|---------------|
| 7.x     | :white_check_mark: | 8.4 and newer |
| 6.4.x   | :white_check_mark: | 8.2 and newer |
| < 6.4.x | :x:                |               |

## Reporting a Vulnerability

Basically, send an email to `richard@teknoo.software` with the description of the vulnerability and a proof of concept
of the exploit. Please do not open a public issue before a fix is released.
This is a free project, written on my free time, so: there is no bug bounty, but you will be credited in the version's
description, changelog and the contributors list.

Thanks
